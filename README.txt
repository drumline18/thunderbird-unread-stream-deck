Thunderbird Unread for Stream Deck on Windows

1. In Thunderbird, open Add-ons and Themes, click the gear icon, select
   Install Add-on From File, and choose Thunderbird-Unread-Bridge.xpi.
2. Double-click Thunderbird-Unread.streamDeckPlugin to install the key.
3. In Stream Deck, drag Thunderbird Unread > Unread Inbox to a key.

The number is the unread total across the physical Inbox folders in
your Thunderbird profile. Pressing the key opens Thunderbird. Keep
Thunderbird running for live counts. A dash means the bridge has not
reported a count recently. It usually reconnects within 10 seconds.

The Thunderbird add-on reads account/folder information. It sends only
the number over localhost and does not use separate login credentials.
